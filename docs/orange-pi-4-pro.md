- `/opt/music-server/web` — собранный сайт.

Для загрузки/удаления через клиент ключ из `/etc/music-api/token` нужно указать
в настройках доступа. Чтение библиотеки и скачивание треков ключа не требуют.

При будущем переносе сначала инвентаризировать данные старого устройства и сделать
копию. Перенести музыку, sidecar-обложки, корзину и кэш/индекс с проверкой хешей.
Не заменять актуальный код, адреса нового устройства и ключ доступа старыми
конфигурационными файлами без отдельной необходимости. SQLite-индекс можно
перестроить; аудиофайлы не заменяются одним файлом базы данных.

## Android и синхронизация

Версия `1.1.2 (45)` использует новые LAN- и Tailscale-адреса. Однократная миграция
DataStore заменяет только прежние стандартные адреса `192.168.1.80:8080` и
`100.106.26.26:8080`; нестандартные адреса, отключённые каналы и последующие ручные
изменения сохраняются. Остальные настройки и локальная музыка не сбрасываются.

Если старое устройство выключено, установленная старая версия приложения может
не найти обновление через его адреса. Для первого обновления указать в настройках
LAN `http://192.168.1.76:8080` либо установить APK нового релиза напрямую.

Веб-клиент выбирает API по origin открытой страницы, поэтому одинаково работает
при открытии нового LAN-адреса и нового Tailscale-адреса.
